# FAQ & troubleshooting

## Installation

**`conda` command not found**
: Install [Miniconda](https://docs.conda.io/en/latest/miniconda.html) and restart your terminal.

**A tool is not found after installation**
: Make sure the right environment is active: `conda activate metabarcoding`.
