# TaxonTableTools overview

**TaxonTableTools (TTT)** is a graphical app for exploring, filtering and
visualising metabarcoding taxon tables.

## What you can do with TTT

- Import taxon tables and metadata
- Filter and clean data (e.g. read thresholds, negative controls)
- Diversity analyses (alpha, beta, ordination)
- Taxonomic overviews and plots
- Export tables and publication-ready figures
