# Overview

The **APSCALE-GUI** bundles Demultiplexer2, APSCALE, APSCALE-blast and
BOLDigger3 in one graphical app. It runs the same steps as the command-line
chapters, so you can use either route.

| Step | Command line | GUI |
|------|--------------|-----|
| Read processing | {doc}`../01_read_processing/index` | {doc}`01_read_processing` |
| Taxonomic assignment | {doc}`../02_taxonomic_assignment/index` | {doc}`02_taxonomic_assignment` |
