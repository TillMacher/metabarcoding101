# Citing the tools

If you use these tools in your research, please cite them and the programs and
databases they rely on.

## Tools

APSCALE and APSCALE-GUI
: Buchner, D., Macher, T.-H., & Leese, F. (2022). APSCALE: advanced pipeline for
  simple yet comprehensive analyses of DNA metabarcoding data. *Bioinformatics*,
  38(20), 4817–4819. <https://doi.org/10.1093/bioinformatics/btac588>

BOLDigger3
: Buchner, D., & Leese, F. (2020). BOLDigger – a Python package to identify and
  organise sequences with the Barcode of Life Data systems. *Metabarcoding and
  Metagenomics*, 4, e53535. <https://doi.org/10.3897/mbmg.4.53535>

TaxonTableTools2
: Macher, T.-H., Beermann, A. J., & Leese, F. (2021). TaxonTableTools — A
  comprehensive, platform-independent graphical user interface software to
  explore and visualise DNA metabarcoding data. *Molecular Ecology Resources*.
  <https://doi.org/10.1111/1755-0998.13358>

Demultiplexer2
: Please cite the [GitHub repository](https://github.com/DominikBuchner/demultiplexer2).

APSCALE-blast
: Please cite the [GitHub repository](https://github.com/TillMacher/apscale_blast).

## Programs used in the background

VSEARCH
: Rognes, T., Flouri, T., Nichols, B., Quince, C., & Mahé, F. (2016). VSEARCH: a
  versatile open source tool for metagenomics. *PeerJ*, 4, e2584.
  <https://doi.org/10.7717/peerj.2584>

Cutadapt
: Martin, M. (2011). Cutadapt removes adapter sequences from high-throughput
  sequencing reads. *EMBnet.journal*, 17(1), 10–12.
  <https://doi.org/10.14806/ej.17.1.200>

Swarm
: Mahé, F., Czech, L., Stamatakis, A., Quince, C., de Vargas, C., Dunthorn, M., &
  Rognes, T. (2022). Swarm v3: towards tera-scale amplicon clustering.
  *Bioinformatics*, 38(1), 267–269. <https://doi.org/10.1093/bioinformatics/btab493>

BLAST+
: Camacho, C., Coulouris, G., Avagyan, V., Ma, N., Papadopoulos, J., Bealer, K., &
  Madden, T. L. (2009). BLAST+: architecture and applications. *BMC
  Bioinformatics*, 10, 421. <https://doi.org/10.1186/1471-2105-10-421>

## Reference databases

Always cite the database you used for taxonomic assignment. References for all
APSCALE-blast databases (MIDORI2, UNITE, SILVA, PR2, diat.barcode, CRUX) are
listed on the [APSCALE-blast page](https://github.com/TillMacher/apscale_blast#databases).
For BOLDigger3, cite BOLD:

BOLD
: Ratnasingham, S., & Hebert, P. D. N. (2007). BOLD: The Barcode of Life Data
  System. *Molecular Ecology Notes*, 7(3), 355–364.
  <https://doi.org/10.1111/j.1471-8286.2007.01678.x>
