## Installation

**`conda` command not found**
: Install Miniconda (see {doc}`../00_getting-started/01_conda_installation`) and restart your terminal.

**A command is not found**
: Check that the right environment is active (`APSCALE4` or `TTT`).

## Still stuck?

Open an issue in the repository of the tool (links on the {doc}`home page <../index>`).
