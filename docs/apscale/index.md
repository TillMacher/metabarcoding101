# APSCALE overview

**APSCALE** is a modular pipeline that turns raw paired-end reads into
ESV and OTU tables.

## Processing steps

1. Paired-end merging
2. Primer trimming
3. Quality filtering
4. Dereplication
5. Denoising (ESVs) and/or clustering (OTUs)
6. Read table generation
